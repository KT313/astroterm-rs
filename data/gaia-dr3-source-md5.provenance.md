# Gaia DR3 source-file manifest

`gaia-dr3-source-md5.txt` is ESA's unmodified main-source checksum list, retrieved 2026-10-10 from:
https://cdn.gea.esac.esa.int/Gaia/gdr3/gaia_source/_MD5SUM.txt

SHA-256: `9ec782f9c83b29885924c7d47bba18d70c86b8cbefbc408b19090b6a76e8e369`

It contains 3,386 GaiaSource filenames and a checksum entry for the manifest itself.
The application sorts the source entries by their numeric HEALPix ranges. Checksums detect corruption;
MD5 is the publisher's format, not a cryptographic authenticity guarantee. Updates must be reviewed.

Credit: ESA/Gaia/DPAC. See the Gaia acknowledgement and release citations in `docs/gaia-dataset.md`.
